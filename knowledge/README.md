# Knowledge

Put course notes, readings, or textbooks in this folder. Pi checks it when a lesson starts and uses relevant passages as source context.

Supported formats: PDF, Markdown, plain text, HTML, JSON, CSV, and common source-code files, up to 50 MB each. Scanned PDFs need OCR before use.

Files in this folder are tracked by Git so the same context is available after cloning. For private or copyrighted material, use the commented opt-out rules in `.gitignore`.
