# Knowledge

Put course notes, readings, or textbooks in this folder. `/teach` indexes it and uses relevant passages as source context. Nested folders are included; files starting with `.` are skipped.

This README is a guide for you. It is not indexed as a source.

Supported formats: PDF, Markdown, plain text, HTML, JSON, CSV, and common source-code files, up to 50 MB each. Scanned PDFs need OCR before use. An empty folder is fine.

Files here are tracked by Git so the same context is available after cloning. For private or copyrighted material, use the commented opt-out rules in `.gitignore`.
