# Resources

The tutor should prefer sources the learner already has, then high-quality public references.

Do not treat this file as a RAG index. Point the researcher at specific URLs or books when known.

## How to add a source

- One line: title, why it matters, and URL or citation
- Keep it short. The concept graph and learning records are the memory, not this list.

## Notes

Web search, when needed, goes through the **researcher** subagent (`pi-web-access` tools), not the tutor turn.
